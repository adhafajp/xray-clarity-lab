# Panduan Data Uji Citra X-Ray

Folder `sample_xray/` berisi 3 citra phantom X-Ray toraks sintetis yang otomatis dibuat agar aplikasi web dan skrip benchmark dapat langsung dijalankan tanpa konfigurasi tambahan.

Untuk pengujian laporan akhir dan draf artikel ilmiah yang lebih komprehensif, tambahkan 15–30 citra X-Ray paru publik berlisensi terbuka (format `.png` atau `.jpg`) ke folder `data/sample_xray/`, misalnya dari dataset publik Kaggle (*Chest X-Ray Images (Pneumonia)* oleh Paul Mooney, lisensi CC BY 4.0) dengan tetap mencantumkan sumber serta lisensi dataset pada laporan.
